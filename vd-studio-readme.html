VD Studio

VD Studio turns rigged 3D models (.glb, .gltf and .fbx) into Ultima Online .vd animation files. It runs on your own computer in your browser; nothing is uploaded anywhere.

What you need

Windows, macOS and Linux are supported. You need Python 3.8 or newer. On Windows, tick Add python.exe to PATH during installation.

The Windows launcher installs the numpy and Pillow packages the first time it runs. Internet access is needed once for that installation.

Starting it

1. Unzip the folder somewhere; do not run it from inside the zip file.

2. Double-click Start VD Studio.bat. A black window stays open while the studio is running.

3. Your browser should open at http://localhost:8765. If it does not, enter that address manually.

4. To stop the studio, close the black window.

Adding models

Models in the imported folder, including its sub-folders, appear in the model list. Sub-folders become groups in the drop-down list.

Use Import model... to select a model. For a .gltf, select the .gltf, its .bin file and its texture images together. Import folder... can be used for a complete folder with textures.

You can also copy files into the imported folder by hand, then reload the page. Imports never overwrite an existing file; duplicate names receive a suffix such as _2.

Open file (not saved)... loads a model for the current session without adding it to the list.

A model needs a skeleton and animations to be useful. Extra animations can be added with Add animations.... For external FBX textures, use Auto-match from folder....

Making a .vd

1. Pick a model and click Load.

2. Choose H for monsters or L for animals and mounts.

3. Click Auto-map to fill the action table, then correct any rows manually.

4. Set the size, camera angle, lighting and other options. Click an action to preview it.

5. Click Render .vd. The finished file appears in the output folder. Rendering again never overwrites an earlier file; it creates _v2, _v3 and so on.

Weapons and attachments

Put weapon or shield models in the weapons folder, or use Add weapon file... in the Attachments panel, then attach them to a creature bone.

Folders

imported — your models
output — finished .vd files and converted FBX copies
weapons — attachment models

Other folders can be used from a terminal, for example: python studio.py --models "D:\my models" --out "D:\my vd" --weapons "D:\my weapons".

macOS and Linux

Install Python 3, then run python3 -m pip install numpy Pillow in a terminal in the VD Studio folder. Start it with ./start.sh or python3 studio.py.

Troubleshooting

Python was not found: install Python and make sure Add python.exe to PATH was selected on Windows.

The page does not load: make sure the black window is still open. If port 8765 is already used, run python studio.py --port 8800 and open http://localhost:8800.

A model looks wrong: check that it has a skeleton and textures, try another Facing offset and use Auto-match from folder... for external textures.

The page looks old after updating: press Ctrl+F5 in the browser.
