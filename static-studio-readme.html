Static Studio

Static Studio renders 3D models into static art for Ultima Online: one PNG per object and view, with a transparent background, lighting and cropping suitable for UO static art. It uses a NumPy software renderer and does not require Blender or a graphics card.

Starting it

Unzip the download anywhere, open the folder and double-click Start UO Static Studio.bat. Keep the black window open while the program runs. Open http://localhost:8766 in your browser. After changing a program file, restart the batch file and press Ctrl+F5.

Python 3.8 or newer, numpy and Pillow are required. The launcher installs the two packages when needed. The fast native renderer is shown as native renderer: ON; OFF uses the slower fallback but produces the same result.

Making a model

The preferred format is glTF Binary (.glb). In Blender, use File → Export → glTF 2.0, choose glTF Binary (.glb), include the selected object and armature, use +Y Up, and export materials and images automatically.

Textures are exported when an image is connected to the Principled BSDF Base Color input. Normal maps should use a Non-Color image through a Normal Map node. A Bump node should be baked to a normal map first.

The studio also reads .obj with .mtl, .dae and binary .fbx files. Put models in the my_models folder, or add other folders from the page.

The camera file

UO_static_render.blend supplies the cameras, orthographic scale, output size and pixel aspect. Four cameras named ItemCam_1 through ItemCam_4 are supported. To use another camera setup, start the program with --blend yourfile.blend.

Using the studio

Choose a model and press Load, then select a camera and rotation. Adjust the style, lighting, picture settings, curves, quality and output size. The preview updates as you work. Press Build PNG to write the result to static_out. Files are never overwritten; later versions receive _v2, _v3 and so on.

The output is cropped to the visible pixels and includes the model-origin position for later placement work. The four rotations option writes the chosen angle plus 0, 90, 180 and 270 degrees.

Place and slice

Open Place and slice renders at the top of the left panel, or visit http://localhost:8766/place. Choose a render, set the tile footprint, move the art into position and select one of these modes:

Vertical strips for tall or multi-tile objects, 44 × 44 diamonds for flat items, or No slicing for one PNG.

Choose a direction and use Preview pieces or Save pieces. Saving creates the PNG pieces and an offsets CSV. With Save as .zip, it also creates a ZIP and an unsliced _preview.png. With No slicing, the single PNG is saved directly into the output folder. The output folder can be chosen in the interface.

Backgrounds and model folders

Place 44 × 44 PNG tiles in the Backgrounds folder to make them available in the preview. Add model folders from the page or with --more "FOLDER" on the batch-file command line.

Animations and spell effects

On the Place and slice page, set Source to Animation (frame sequence). Numbered PNG frames such as spell_001.png and animated GIFs can be loaded as frame sequences. Frames from the render studio use their saved origin; other frames use the centre of the picture unless a matching JSON origin file is present.

The animation controls include Play/Pause, FPS, a frame slider and per-frame or all-frame shifting. An anchor frame can be shown through the current frame to help align the sequence. Animations can be sliced with Vertical strips or 44 × 44 diamonds.

With No slicing, saving creates a ZIP containing the frames and a looping transparent _preview.gif. When sliced, each tile gets its own folder with the tile frames and CSV. The GIF preview uses hard transparency, so soft glow edges may look rougher than the PNG frames.

Keep frames can reduce the frame count while retaining the first and last frames. Scale % downsizes every frame with transparency-aware resampling. Both options work before placing and slicing.

Important notes

Static model rendering uses the bind pose; animation sequences are handled separately on the Place and slice page. Shadows already baked into textures are not removed. The studio does not currently create UO item art (.mul or .uop) output.

Troubleshooting

The window closes or Python is missing: install Python 3.8 or newer and make sure it is available on your PATH.

The page does not load: keep the black window open. If port 8766 is already in use, run python studio_static.py --port 8800 and open http://localhost:8800.

A model looks wrong: check its skeleton, textures and up-axis setting. Try the other Facing offset values and use Auto-match from folder... for external textures.
