Levy's download tool for Vrark-Art

A small program for browsing the monster (H) and animal/mount (L) animations from the Vrark Art website. You can preview them, change their colours and sort them into your own folders.

Before you start

You need Python 3 installed. If you do not have it, download it from python.org and tick Add python.exe to PATH during installation. You do not need to install anything else.

How to use it

Step 1 — Download the animations.
Double-click download.bat. A black window opens and starts downloading all animations into the H and L folders. It is several GB, so it may take a while. You can close the window at any time and run it again later; it continues where it stopped.

Step 2 — Start the viewer.
Double-click start.bat. Your browser opens the viewer at http://127.0.0.1:8766/. Keep the black window open while using the viewer.

Step 3 — Browse.
Pick H or L at the top, choose an animation on the left and play with it in the middle. If you downloaded more files while the viewer was open, click Refresh list.

Changing colours (hues)

The viewer does not include a hues.mul file. You can click Load hues.mul... in the Hue panel and choose your own file, or use the colour picker in the same panel to tint the animation.

Sorting your animations

Click + New folder to make a folder, then move the selected animation into it with the buttons on the right, by dragging it onto a folder, or with Shift plus the number keys.

Delete does not permanently delete anything. The file goes to the _trash folder and can be restored with Ctrl+Z.

Files you moved or deleted will not be downloaded again when you run download.bat.

If something goes wrong

Python was not found: install Python as described above and try again.

Some files failed to download: Google Drive sometimes blocks too many downloads. Run download.bat again.

The port is already in use: close other copies of the viewer, or ask the person who supplied it for a different port.

The viewer is empty: download the animations first, then click Refresh list.

What is in the folder

H, L — downloaded animations
_trash — animations removed in the viewer
hues.mul — your own hues file, if loaded
_app — the program itself
